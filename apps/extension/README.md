# @ranklark/extension

Chrome MV3 extension that checks App Store ranks for your own keywords from your own browser. It needs no
login: opening your dashboard connects it, or you enter the dashboard address in the popup.

```bash
pnpm ext:build   # from the repo root → load apps/extension/dist in chrome://extensions
```

Full guide (how it works, privacy, end-to-end test, publishing): [docs/extension.md](../../docs/extension.md)
